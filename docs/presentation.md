# 발표 운영 메모

발표 장소에서 같은 네트워크의 다른 PC(강사님 PC 등)로 접속시키고, 시작 전에 데이터를 초기화하는 절차입니다.
설치와 `.env` 설정은 [README의 실행 방법](../README.md#실행-방법)을 먼저 마친 상태를 기준으로 합니다.

> 이 문서에는 실제 IP 주소 · DB 접속 정보 · 계정 비밀번호를 적지 않습니다. 접속 주소는 실행할 때 화면에 나오는 값을 쓰고, 데모 계정은 README의 "데모 계정" 표를 봅니다.

## 1. 처음 한 번 — 방화벽 열기

다른 PC가 이 PC의 8000번 포트로 들어올 수 있게 Windows 방화벽에서 TCP 8000 인바운드를 허용합니다 (관리자 PowerShell).

```powershell
New-NetFirewallRule -DisplayName "KonaBiz 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private,Public
```

## 2. 발표 장소에 도착하면 — DB 접속 허용

MongoDB Atlas의 **Network Access**에 지금 네트워크의 공인 IP를 추가합니다.
장소가 바뀌면 공인 IP도 바뀌므로, 추가하지 않으면 로그인 · 예약 · 결제 테스트가 DB 오류로 실패합니다.

## 3. 발표 전 초기화

```powershell
cd backend
.venv\Scripts\activate
python -m scripts.seed
```

- `users` · `cards` · `reservations` · `chats` 4개 컬렉션을 비우고 데모 데이터를 다시 넣습니다 (몇 번 실행해도 결과가 같고, 다른 컬렉션은 건드리지 않음)
- 같이 지워지는 것: 결제 테스트로 쌓인 결제와 차감된 포인트, 새로 초대한 임직원, 상담 예약, 챗봇 대화
- 초기화 직후 화면 (리허설 때 이 숫자인지 확인)

| 화면 | 값 |
|---|---|
| 임직원 마이페이지 (김민준) | 남은 포인트 272,000원 · 법인경비P 488,000원 · 결제내역 7건 |
| 관리자 대시보드 | 활성 카드 18장 · 발급 중 3 · 이번 달 차단 1건 (seed 거래 날짜가 2026년 10월 고정이라 10월 기준) |
| 상담 예약 | 마감 칸 3개 (seed 실행일 다음 평일들) |

- 서버가 떠 있어도 실행할 수 있습니다 (서버 재시작 불필요). 코드를 바꿨다면 서버는 다시 시작합니다

## 4. 서버 띄우기 — 다른 PC에서 접속

1. `backend\run_lan.bat` 실행 (탐색기에서 더블클릭)
   - 가상환경을 켜고, 다른 PC가 쓸 접속 주소(`http://192.168.x.x:8000` 형태)를 출력한 뒤 서버를 띄웁니다
   - 자동 새로고침(`--reload`)이 없어 파일을 저장해도 서버가 다시 시작되지 않습니다
2. 다른 PC 브라우저에서 출력된 주소로 접속합니다
3. 끄기는 서버 창에서 Ctrl+C
4. 서버 창은 빠른 편집(QuickEdit)을 끈 상태로 뜨므로 창을 클릭해도 멈추지 않습니다. 그래도 응답이 멈추면 그 창에서 Esc

직접 실행하려면 (`backend` 폴더, 가상환경을 켠 상태):

```powershell
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- `--host 0.0.0.0`이 없으면 이 PC(localhost)에서만 열립니다
- 주소 · 링크 · API 호출은 모두 상대 경로라 IP 주소로 접속해도 그대로 동작합니다. http라서 `.env`의 `COOKIE_SECURE=false`를 유지합니다
- 임직원 초대 완료 창의 [로그인 정보 복사]도 IP 주소(http)에서 동작합니다 (브라우저 클립보드 API가 막히면 대체 방법으로 복사)
- 인터넷 연결이 필요합니다: DB(Atlas) · 챗봇 직접 입력(OpenAI) · 글꼴(Pretendard CDN). 글꼴만 실패하면 기본 글꼴로 보입니다

## 5. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 로그인 · 예약이 "일시적인 오류" | Atlas Network Access에 지금 공인 IP가 있는지 (2번) |
| 다른 PC에서 접속이 안 됨 | 방화벽(1번), 같은 네트워크인지, `run_lan.bat`(또는 `--host 0.0.0.0`)으로 띄웠는지 |
| 서버 응답이 멈춤 | 서버 창에서 Esc |
| 시연 중 숫자가 꼬임 | 3번 초기화 후 브라우저 새로고침 |
| 외장하드 드라이브 문자가 바뀐 뒤 `.venv` 오류 | `backend\.venv`를 지우고 README 실행 방법대로 다시 만들기 |
